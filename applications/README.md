# Specific Applications

Since you are applying to a lot of positions, it is a best practice to **tailor your resume** to each job description.

**How to use this folder:**
1. Whenever you find a job you want to apply to, create a new folder inside here. For example: `applications/Google_Software_Engineer/`
2. Copy your `base_resume.md` and `cover_letter_template.md` into that new folder.
3. Edit the copied resume and cover letter to match the specific keywords and requirements of that job.
4. Export them to PDF to send to the employer.

This keeps your applications highly organized and prevents you from accidentally sending the wrong resume to a company!
